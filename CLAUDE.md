# DMarket Resale Bot

## Что это

Discord-бот для поиска выгодных лотов на DMarket для перепродажи CS2-скинов.
Сканирует маркет, сравнивает минимальный оффер со стороны продавцов с максимальным таргетом (buy order) покупателей, считает чистую прибыль после комиссии 10%, и постит сигналы в Discord с кнопкой-ссылкой на скин.

## Файлы

- `dmarket.py` — API-клиент DMarket: получение лотов, маркет-дефф (таргеты), форматирование
- `bot.py` — Discord-бот: сканирует в цикле, шлёт сигналы в канал `CHANNEL_ID`
- `best.py` — standalone-версия (без Discord), выводит в консоль
- `.env` — `DISCORD_TOKEN`

## Ключевая логика

```
net = (offer_price * 0.90) - max_target
```

Фильтр: `net >= 1` и `net <= 10` (в `dmarket.py`), `net >= 1` в `best.py`.
Цена оффера не выше $100.

## API

- Аутентификация: HMAC-SHA256 подпись (`X-Request-Sign: dmarket <hex>`)
- Лоты: `GET /exchange/v1/market/items?gameId=a8db&types=dmarket&...`
- Таргеты: `GET https://api.dmarket.com/order-book/v1/market-depth?title=...&gameId=a8db`

Ключи лежат хардкодом в `dmarket.py` и `best.py` — при рефакторинге вынести в `.env`.

## Что нужно улучшить (приоритет: средний)

- **Фильтр ликвидности**: среднее кол-во продаж за период, средняя цена продажи, среднее значение таргета, кол-во покупок с таргета. Скины с низкой ликвидностью отсеивать.
- **Trade protected**: пропускать предметы, защищённые от трейда (нужно найти поле в API-ответе, логика пока не определена).

## Что нужно добавить (приоритет: высокий)

- **Сравнение с другими сайтами**: Steam Community Market, Skinport, CS.Money — для более точной оценки реальной цены.
- **Авто-перебивка таргета**: если мой таргет перебили — получить сигнал. Если перебили незначительно (например, на $0.01–0.05) — автоматически перебить обратно.
- **Сигнал о покупке в Discord**: когда предмет купился у меня, прислать сообщение с названием скина, ценой покупки, ценой продажи, ожидаемой прибылью.
- **Авто-выставление на продажу**: после покупки автоматически выставлять скин по цене минимального оффера (или с небольшим занижением).

## Идеи на будущее (приоритет: низкий)

- **Поиск по float**: поддержка фильтрации по износу (например, перчатки) — сравнивать цену конкретного флоата с аналогами, автоматизировать весь цикл.
- **Отслеживание отдельных скинов**: ставить таргеты на конкретные отфильтрованные скины и следить за ними отдельно.
